# README: Скрипты для расчета абсолютных валютных курсов AbsCur3

## 📋 Общее описание

Этот каталог содержит скрипты, реализующие систему расчета **абсолютных валютных курсов** методом наименьших квадратов. Система принимает валютные пары (например, $`EUR/USD`$, $`USD/JPY`$) и вычисляет внутренне согласованные абсолютные курсы валют, минимизируя расхождения рыночных данных.

## 🎯 Математическая основа

### Основная модель
Для каждой валютной пары $`i/j`$ на дату $`t`$ справедливо уравнение:

```math
P_{ij}(t) = \frac{A_i(t)}{A_j(t)} \cdot \bigl(1 + \epsilon_{ij}(t)\bigr)
```

где:
*   $`P_{ij}(t)`$ — наблюдаемый рыночный курс закрытия пары,
*   $`A_i(t)`$, $`A_j(t)`$ — искомые абсолютные курсы валют,
*   $`\epsilon_{ij}(t)`$ — относительная ошибка модели.

### Линейная модель и её решение
После логарифмирования и линеаризации для малых $`\epsilon`$ получаем линейную систему:

```math
\ln \bigl(P_{ij}(t)\bigr) \approx \ln \bigl(A_i(t)\bigr) - \ln \bigl(A_j(t)\bigr) + \epsilon_{ij}(t)
```

Для каждой даты $`t`$ эта система записывается в матричной форме $`M(t) \cdot \vec{a}(t) = \vec{p}(t)`$, где:
*   $`M(t)`$ — матрица инцидентности доступных пар,
*   $`\vec{a}(t)`$ — вектор логарифмов абсолютных курсов,
*   $`\vec{p}(t)`$ — вектор логарифмов рыночных курсов.

Решение $`\vec{a}(t)`$, минимизирующее евклидову норму невязки $`\| M(t) \cdot \vec{a}(t) - \vec{p}(t) \|^2`$, находится методом наименьших квадратов.

### Ключевые свойства решения
1.  **Инвариантность**: Система имеет бесконечное семейство решений, различающихся на аддитивную константу в логарифмах (мультипликативную — в абсолютных курсах). Все решения удовлетворяют $`\vec{a}' = \vec{a} + C \cdot \vec{1}`$.
2.  **Естественная нормировка**: Алгоритм возвращает решение, для которого $`\sum \ln(A_i) = 0`$ (среднее логарифмов равно нулю). Это эквивалентно условию $`\prod A_i = 1`$.
3.  **Согласованность парных курсов**: Отношения абсолютных курсов $`A_i / A_j`$ воспроизводят исходные парные котировки с минимальной среднеквадратичной погрешностью.

## 📊 Форматы данных и результаты

### Входные данные
*   **Источник**: `data/raw/twelve_data/pairs/{PAIR}.csv`
*   **Формат**: CSV с колонками `datetime` (или `timestamp`), `open`, `high`, `low`, `close`.
*   **Используется**: Только цена закрытия `close`.

### Выходная структура (`data/absolute/`)
Результаты сохраняются в соответствии с техническим заданием:

```
data/absolute/
├── daily/                    # Абсолютные курсы на каждую дату
│   └── YYYY-MM-DD.csv       # Колонки: currency, absolute_value
├── currencies/              # История по каждой валюте
│   └── {CURRENCY}.csv      # Колонки: date, absolute_value
├── errors/                  # Детальные погрешности восстановления пар
│   └── YYYY-MM-DD.csv      # Колонки: pair, actual_value, calculated_value, error_percent
└── metadata/                # Отчеты, статистика, результаты тестов
    ├── daily_statistics.csv
    ├── test_30day_statistics.json
    └── step8_final_report.json
```

**Важно**: Абсолютные курсы в файлах соответствуют **естественной нормировке**, где $`\prod A_i = 1`$. Для получения курса пары $`i/j`$ рассчитайте $`P_{ij} = A_i / A_j`$.
